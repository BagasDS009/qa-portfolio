# 03 - Database Testing

## Overview
SQL-based database testing for validating data integrity, user records, and order transactions.

## Tech Stack
- MySQL / PostgreSQL
- SQL queries
- Manual & automated validation

## Project Structure
```
03-database-testing/
├── queries/                 # SQL validation scripts
│   ├── user_validation.sql
│   ├── order_validation.sql
│   └── data_integrity.sql
└── test-cases/              # Database test case documentation
```

## Test Coverage
- User data validation (CRUD operations)
- Order transaction validation
- Data integrity & constraint checks
- Foreign key relationships
- Duplicate detection
