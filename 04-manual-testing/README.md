# 04 - Manual Testing

## Overview
Comprehensive manual testing documentation including test plans, test cases, bug reports, and summary reports.

## Project Structure
```
04-manual-testing/
├── test-plan.md              # Master test plan document
├── test-scenarios.xlsx       # High-level test scenarios
├── test-cases.xlsx           # Detailed test cases
├── bug-report.md             # Bug report samples
└── test-summary-report.md    # Test execution summary
```

## Documents
| Document | Description |
|----------|-------------|
| Test Plan | Strategy, scope, schedule, and resources |
| Test Scenarios | High-level feature scenarios |
| Test Cases | Step-by-step test execution details |
| Bug Report | Defects found during testing |
| Summary Report | Overall test execution results |
