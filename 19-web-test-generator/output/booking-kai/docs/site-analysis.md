## User Flows

### Flow 1: Search & Book Train (Critical — Revenue Path)

1. User navigates to homepage
2. Types origin station → selects from dropdown
3. Types destination station → selects from dropdown
4. Clicks date field → navigates calendar → clicks day
5. Sets adult count (default 1)
6. Clicks "Cari" (Search)
7. **Page reloads** → Train list displayed
8. User reviews trains (name, price, time, class, availability)
9. Clicks "Select" on desired train
10. **Page reloads** → Passenger form displayed
11. Fills contact person (name, phone, email, ID)
12. Fills passenger data (name, ID number)
13. Clicks "Lanjutkan"
14. **Page reloads** → Seat map displayed
15. Selects available seat (or skip)
16. Clicks "Konfirmasi"
17. **Page reloads** → Payment page (booking code generated)
18. Selects payment method
19. ⚠️ STOP HERE in automation

**Failure points:**
- Step 2-3: Dropdown not appearing (timing), station not found
- Step 4: Datepicker navigation (month not found, day disabled)
- Step 7: No trains available (wrong date/route)
- Step 9: Train sold out between listing and click
- Step 11-12: Validation fails (NIK format, empty fields)
- Step 15: All seats occupied
- Step 17: Session expired during flow

### Flow 2: Login

1. Navigate to homepage (or login page)
2. Enter username (email/phone)
3. Enter password
4. Click Login
5. Wait for redirect / profile icon
6. Verify logged in state

**Failure points:**
- Wrong credentials → iziToast red error
- Empty fields → form validation
- Account locked (too many attempts)
- CAPTCHA triggered

### Flow 3: Search Edge Cases

| Input | Expected |
|-------|----------|
| Same origin & destination | Error / blocked |
| Past date | No results or validation error |
| Baby > Adult count | Tooltip "Tidak bisa melebihi penumpang dewasa" |
| Max adults (4) + search | Results shown (limit respected) |
| Empty station fields | Validation error |
| Non-existent station | No dropdown match |
