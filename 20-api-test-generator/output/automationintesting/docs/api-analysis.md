## API Overview

- **Base URL**: `https://automationintesting.online/api`
- **Auth**: Cookie-based — `POST /auth/login` → response `{"token":"xxx"}` → set `Cookie: token=xxx`
- **Format**: JSON (request & response)

## Auth Flow

```
1. POST /api/auth/login {"username":"admin","password":"password"}
   → Response: {"token":"onsbOp3SMzLxknqs"}

2. All subsequent requests:
   Header: Cookie: token=onsbOp3SMzLxknqs

3. Without cookie: 401 {"error":"Authentication required"}
4. Invalid credentials: 401 {"error":"Invalid credentials"}
```
