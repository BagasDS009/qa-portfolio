# API Automation — Restful Booker Platform

Pytest + httpx automation suite for [automationintesting.online](https://automationintesting.online/api) with Allure reporting.

## Setup

```bash
# Create virtual environment
python3.13 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Install Allure CLI (for report viewing)
brew install allure
```

## Running Tests

```bash
# All tests
pytest

# Smoke tests only
pytest -m smoke

# Specific feature
pytest tests/test_auth.py

# By marker
pytest -m security
pytest -m "smoke and not performance"
pytest -m contract

# With verbose output
pytest -v -m wave1
```

## Test Markers

| Marker | Description |
|--------|-------------|
| `smoke` | Core happy-path tests (run first) |
| `wave1` | All functional tests |
| `contract` | Schema/response format validation |
| `security` | Auth bypass, injection, OWASP Top 10 |
| `performance` | Response time budget assertions |
| `negative` | Error handling / invalid input |
| `auth` | Authentication-specific tests |
| `edge` | Boundary value tests |

## Allure Report

After test execution, the report auto-opens in your browser. To manually view:

```bash
allure serve reports/allure-results
```

## Environment Configuration

Copy and customize for different environments:

```bash
cp config/.env.sit config/.env.staging
ENV=staging pytest
```
